# Data folder

| File | Schema | Purpose |
|---|---|---|
| `processed/nodes.csv` | `city, lat, lon, type` | Graph nodes — 15 Indian cities with coordinates |
| `processed/edges.csv` | `origin, destination, distance_km, hist_avg_delay_hrs` | Directed routes between cities |
| `processed/shipments.csv` | generated by `ml/preprocess.py` | Synthetic training data with `delayed` label |
| `raw/` | (empty) | Drop Olist or other real CSVs here later |

`nodes.csv` and `edges.csv` are committed by hand (Stage A — see DESIGN.md §6.1).
`shipments.csv` is generated programmatically (Stage B — §6.2).
